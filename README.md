# SILA MD — بوت واتساب

بوت واتساب متعدد الميزات مبني باستخدام Node.js ومكتبة Baileys.

## المتطلبات
- Node.js 18 أو أحدث.
- تثبيت الاعتماديات باستخدام `npm install --legacy-peer-deps`.
- تشغيل البوت باستخدام `npm start`.

## الربط
يمكن ربط واتساب باستخدام رمز الربط من خلال أمر `.bot` أو `.pair` بحسب إعدادات المشروع. افتح واتساب ثم الإعدادات ← الأجهزة المرتبطة ← ربط جهاز، واتبع التعليمات الظاهرة. لا تشارك رمز الربط مع أي شخص.

## أوامر الحالات
- `.autostatus` — عرض إعدادات الحالات.
- `.autostatus on` — تفعيل مشاهدة الحالات تلقائيًا.
- `.autostatus off` — إيقاف المشاهدة.
- `.autostatus react on` — تفعيل التفاعل مع الحالات.
- `.autostatus react off` — إيقاف التفاعل.
- `.autostatus emoji ❤️` — اختيار إيموجي التفاعل.
- `.autostatus viewonly` — مشاهدة الحالات دون تفاعل.
- `.autostatus both on` — تفعيل المشاهدة والتفاعل.
- `.autostatus none` — إيقاف المشاهدة والتفاعل.

## تنبيه
قد تختلف بعض الميزات حسب إصدار Baileys وحالة اتصال واتساب. اختبر المشروع في بيئة تجريبية واحتفظ بنسخة احتياطية من مجلد `session` قبل أي تحديث.


## النشر على Render

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. من Render اختر **New → Blueprint** واربط المستودع الذي يحتوي على `render.yaml`.
3. سيتم إنشاء Background Worker وتثبيت الحزم باستخدام `npm install --legacy-peer-deps`.
4. أضف متغير البيئة `OWNER_NUMBER` في إعدادات الخدمة، بصيغة دولية مع الأرقام فقط، إذا أردت تغييره عن الرقم الموجود في `settings.js`.
5. اربط واتساب باستخدام رمز الربط الذي يظهر في سجلات الخدمة. لا تشارك الرمز أو ملفات الجلسة.
6. احتفظ بنسخة احتياطية آمنة من بيانات الجلسة قبل إعادة النشر أو تغيير الإعدادات.

**مهم:** ملف `render.yaml` يستخدم خطة مدفوعة تدعم القرص الدائم حتى لا تضيع جلسة واتساب عند إعادة التشغيل. لا ترفع مجلد `session` أو أسرار الاتصال إلى GitHub. اختبر الميزات التي تعتمد على واجهات API الخارجية بعد النشر؛ لا يمكن ضمان عمل كل خدمة خارجية دائمًا.
